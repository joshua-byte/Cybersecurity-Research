# Cybersecurity Research

A collection of computational research projects exploring network security, graph algorithms, adversarial propagation, and predictive modelling.

## Projects

### 1. Entropy-Aware Routing for Disorder Minimization
Studies traffic-disorder-aware routing and its potential to improve network robustness under adversarial conditions.

### 2. LambdaShield
A graph-based simulator for modelling network attack propagation and evaluating network resilience.

### 3. HNN
A graph-based forecasting experiment comparing infection-rate predictions against baseline models.


## Reproducibility

Each project maintains its own code, dependencies, datasets, and experimental outputs. Refer to the individual project documentation for setup and execution instructions.
