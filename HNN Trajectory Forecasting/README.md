# HNN Trajectory Forecasting

A research project investigating the forecasting of post-infection trajectories on network topologies using Hamiltonian Neural Networks (HNNs) and baseline methods.

## Overview

This project evaluates HNN-based forecasting against persistence, linear extrapolation, and ARIMA baselines. It uses graph-based data to investigate how infection-rate dynamics evolve over time and how well different methods predict future trajectories.

## Methods

- Hamiltonian Neural Networks (HNN)
- Persistence baseline
- Linear extrapolation
- ARIMA forecasting
- Comparative model evaluation

## Repository Contents

- Jupyter notebook containing the experiment and analysis
- Evaluation outputs from recorded runs
- Graph edge-list data used in the experiment

## Reference

The network dataset and graph structure draw on work on social circles in ego networks:

McAuley, J., & Leskovec, J. (2012). [Learning to Discover Social Circles in Ego Networks](http://i.stanford.edu/~julian/pdfs/nips2012.pdf). *Advances in Neural Information Processing Systems (NIPS)*.
